# Ошибки API «Документы» V2

Все ошибки самого модуля возвращаются в формате:

```json
{"detail": "Сообщение"}
```

## 400 Bad Request

- `Подтвердить получение можно только для готовой заявки`

## 401 Unauthorized

Общие ошибки JWT-авторизации:

- `Not authenticated`
- `Invalid or expired token`
- `Invalid token subject`
- `User not found or inactive`

## 402 Payment Required

Если общая middleware лицензирования заблокировала API:

- `License is not active`

Поле `reason` в этом ответе содержит конкретную причину ошибки лицензии.

## 403 Forbidden

- `Forbidden (role)`
- `Профиль студента не найден`
- `Нельзя подтвердить получение чужой заявки`
- `Нельзя удалить заявку другого студента`
- `Можно удалить только новую заявку`

Если функция недоступна по тарифу, используется динамическое сообщение:

- `Feature 'applications' is not available for tariff '<tariff>'`

## 404 Not Found

- `Заявка на документ не найдена`
- `Ссылка на выгрузку недействительна или истекла`

## 422 Unprocessable Entity

- `Обязательное поле не заполнено: <field>`
- `Поле <field> должно быть целым числом`
- `Поле <field> должно быть строкой`
- `Недопустимое значение поля <field>`
- `Тело запроса должно быть JSON-объектом`
- `Некорректный JSON`
- `Поле не может быть пустым`
- `Количество экземпляров должно быть от 1 до 10`
- `Для справки об обучении период выплаты должен быть null`
- `Для справки об обучении произвольный период должен быть null`
- `Для справки о выплате стипендии необходимо указать период`
- `Для произвольного периода необходимо указать его значение`
- `Произвольный период должен быть null для выбранного периода выплаты`
- `В профиле студента не указано ФИО`
- `Группа студента не найдена`
- `Текст заявки на книгу не может быть пустым`
- `Текст заявки на книгу не должен превышать 2000 символов`
- `Текст заявки на книгу должен быть null для заявки на документ`
- `Дата начала периода не может быть позже даты окончания`

В динамических сообщениях `<field>` заменяется именем поля, например
`copies_count`, `order_location` или `status`.
