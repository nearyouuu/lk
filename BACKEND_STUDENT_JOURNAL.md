# Доступ студента к учебному журналу

Backend использует те же endpoints журнала, что и для преподавателя. Отдельный frontend-контракт не требуется.

## Права

Роли `student` выдаётся permission `journal.read`. Запись, изменение тем, закрытие периода и аудит студенту не выдаются.

Дисциплина доступна студенту, если:

- у пользователя существует профиль `students`;
- студент состоит в запрошенной группе;
- для группы и дисциплины существует активный `journal_assignment` в выбранном семестре.

## Каталог дисциплин

```http
GET /lk/api/v1/journal/catalog?academic_year=2026&semester=autumn
```

Для студента ответ содержит только его группу и назначенные этой группе дисциплины:

```json
{
  "academic_year": 2026,
  "semester": "autumn",
  "access_scope": "self",
  "groups": []
}
```

## Просмотр выбранной дисциплины

```http
GET /lk/api/v1/journal?group_id=201&subject_id=101&date_from=2026-09-01&date_to=2026-12-31
```

В студенческом ответе:

- `students` содержит только текущего студента;
- `entries` содержит только его посещаемость и оценки;
- `lessons` содержит только опубликованные даты журнала;
- `permissions.can_edit = false`;
- `permissions.can_manage_topics = false`;
- `access_scope = "self"`.

Попытка запросить другую группу или дисциплину без активного назначения возвращает `403 JOURNAL_ACCESS_DENIED`.

`GET /journal/groups/{group_id}/students` также возвращает студенту только его собственный профиль. Excel-выгрузка `/journal/export` содержит только строку текущего студента.
